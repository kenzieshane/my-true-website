KS Lyrics!

Overview & Features

KS Lyrics is a lightweight Windows 8+ lyrics viewer and player focused on clarity, performance, and easy sharing.

Autoscroll

Auto-scroll lyrics in sync with the track or using a custom timer so singing along is effortless.

Create Your Own

Compose and save your own lyric files locally using a simple editor inside the app. (Trust me, it's really basic, but it works.)

Adjust Speed

Custom autoscroll speed control with presets and fine-grain adjustment for perfect timing. (Yapping ahh)

Featured Lyrics

Browse featured, pre-made lyric packs downloaded on demand. Packs can be cached for offline use.

Background Playback

Play the original track in the background while the lyrics scroll, with support for common audio formats.

Ultra SUPER Deluxe Premium Bazinga Lightweight

Minimal dependencies, optimized for low RAM/CPU usage, yes that means our app follows the Metro design philosophy: fast, clean, and content-first.

How it works: featured lyric packs are served from a simple JSON API and downloaded as small text bundles; local saves use the filesystem (appx-sandbox aware) so users can keep offline copies.

This app is a metro app!
